# Only One Suivi

Appli de suivi clients, prestations et prospection d'Only One (Leutenheim, Alsace).

Page statique hébergée sur GitHub Pages. Les données sont dans Supabase et ne sont accessibles qu'après connexion avec le compte d'Only One.

Fichiers : `index.html` (l'appli), `shim.js` (connexion et base Supabase), `config.js` (adresse du projet Supabase), `supabase/schema.sql` (structure de la base).
